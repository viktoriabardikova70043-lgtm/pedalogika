# PEDALOGIKA — как запустить настоящую версию

Этот набор файлов — стартовая точка для полноценного приложения
(с логином, базой данных, доступом ученика/родителя). Ниже — куда
класть код и в каком порядке действовать, шаг за шагом.

## Шаг 1. База данных (Supabase) — 5 минут

1. Зайдите на **** → Sign up → New project (бесплатно).
2. В панели проекта откройте **SQL Editor** → New query.
3. Скопируйте туда весь файл `supabase/schema.sql` из этого пакета и
   нажмите **Run**. Это создаст все таблицы: учеников, занятия,
   навыки, маршруты, ДЗ, абонементы и т.д., со связями между ними.
4. Слева в меню откройте **Project Settings → API** — там будут два
   значения, которые понадобятся дальше: `Project URL` и `anon public key`.

## Шаг 2. Код приложения (Next.js)

Вам нужен компьютер с установленным **Node.js** (nodejs.org, версия 18+).

1. Создайте папку проекта и скопируйте туда файлы из этого пакета,
   сохраняя структуру:
   ```
   pedalogika/
     package.json
     lib/supabaseClient.js
     app/login/page.js
     app/dashboard/page.js
     supabase/schema.sql   (уже использован в Шаге 1, можно оставить для истории)
   ```
2. В корне проекта создайте файл `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=вставьте_Project_URL_из_Шага_1
   NEXT_PUBLIC_SUPABASE_ANON_KEY=вставьте_anon_public_key_из_Шага_1
   ```
   Этот файл никогда не выкладывается в открытый доступ.
3. В терминале, в папке проекта:
   ```
   npm install
   npm run dev
   ```
4. Откройте `http://localhost:3000/login` — увидите форму входа,
   уже подключённую к настоящей базе данных.

## Шаг 3. Перенос интерфейса из демо-версии

Дизайн и весь UI, который вы видели в чате (dashboard, карточка
ученика, маршрут, конструктор уроков и т.д.), нужно перенести из
файла `pedalogika.jsx` в отдельные страницы Next.js (`app/students/page.js`,
`app/students/[id]/page.js` и т.д.), заменив `useState` на запросы
через `supabase.from(...)`. Это самая объёмная часть работы —
собственно перенос бизнес-логики на реальные данные.

**Именно на этом шаге лучше всего подключить Claude Code** — он
может открыть оба файла у вас на компьютере, писать код прямо в
проект и сразу проверять, что всё запускается.

## Шаг 4. Публикация в интернет (Vercel) — 5 минут

1. Загрузите папку проекта в GitHub (создайте новый репозиторий).
2. Зайдите на **vercel.com** → Add New Project → выберите этот репозиторий.
3. В настройках проекта на Vercel добавьте те же переменные, что и
   в `.env.local` (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`).
4. Нажмите Deploy. Через минуту получите постоянный адрес вроде
   `pedalogika.vercel.app` — уже доступный с любого устройства.

## Что дальше

Дальше — по плану из вашего исходного ТЗ (раздел «Первый этап
разработки»): ученики → карточка ученика → диагностика → маршрут →
журнал занятий → база заданий → конструктор уроков → ДЗ → абонементы →
графики → личные кабинеты → AI-функции. Каждый пункт — это набор
Next.js-страниц + Supabase-запросов, построенных по образцу
`app/dashboard/page.js` в этом пакете.
